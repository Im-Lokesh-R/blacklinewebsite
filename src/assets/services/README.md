# Service images

One folder per service (folder name = the service `id` in `src/content.ts`).
Drop photos in a folder and they show up automatically, in filename order,
when that service is clicked in the Services section.

Supported: .jpg .jpeg .png .webp .avif
Tip: name files 1.jpg, 2.jpg, 3.jpg ... to control the order.

The photos currently in each folder are placeholders — replace them with real work for that service.
